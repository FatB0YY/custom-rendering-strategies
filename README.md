# Custom Rendering Strategies

Этот репозиторий содержит различные кастомные реализации стратегий рендеринга и их оптимизаций в React. Главная ценность репозитория в том, что здесь можно увидеть низкоуровневые механизмы, которые обычно скрывает framework.

## Содержание

- **custom-isr**  
  Кастомная реализация Incremental Static Regeneration (ISR).

- **custom-partial-ssg**  
  Частичная генерация статики во время билда (Partial Static Site Generation).

- **custom-ssg**  
  Полная генерация статики (Static Site Generation).

- **custom-ssi**  
  Пример серверных включений (Server Side Includes, SSI).

- **custom-ssr**  
  Классический серверный рендеринг (Server Side Rendering, SSR).

- **custom-ssr-slow-request**  
  Имитация медленного SSR-запроса.

- **custom-ssr-stream**  
  Потоковый серверный рендеринг (SSR streaming) для снижения TTFB.

- **react-csr**  
  Клиентский рендеринг с использованием React (Client Side Rendering, CSR).

- **react-csr-app-shell**  
  Реализация CSR с подходом App Shell для быстрого начального отклика.

- **stream**  
  Демонстрации стриминга данных.
